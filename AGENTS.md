# MyCampusToCareer project conventions

- All product UI must be in English. This includes navigation, forms, placeholders,
  validation messages, accessible labels, metadata, empty states and emails.
- Format interface numbers and dates in English. Display dates in Asia/Dhaka.
- Preserve student-entered content as submitted; do not translate stored profiles.
- Keep the agreed stack: Next.js and Tailwind CSS for the frontend, NestJS for the
  API, PostgreSQL and Prisma for data access.
- New features should follow the seven modules in the project specification.
  The current first phase covers accounts, student profiles and admin access.
- Follow the generated Next.js guidance in apps/web/AGENTS.md for frontend edits.
